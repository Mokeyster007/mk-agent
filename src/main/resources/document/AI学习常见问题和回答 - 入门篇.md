# AI 学习常见问题和回答 - 入门篇
#### 人工智能、机器学习和深度学习是什么关系？
三者是一种层层包含的关系。人工智能（AI）是最宽泛的概念，指让机器模拟人类的学习、推理与感知等智能行为；机器学习（ML）是 AI 的核心分支，强调让机器从数据中自动总结规律，而不是靠人工硬编码规则，例如给模型看大量猫的图片，它自己归纳出"猫"的特征；深度学习（DL）则是机器学习的一个子集，使用多层神经网络处理复杂数据，是驱动 ChatGPT、Midjourney 等生成式 AI 的核心技术。简单总结：所有的深度学习都属于机器学习，所有的机器学习都属于人工智能，反之则不成立。理清这层关系是学习 AI 的第一步，可以避免在查阅资料时被各种术语绕晕。
推荐资源：[《零基础学AI：AI Beginner Guide》](https://yeasy.gitbook.io/ai_beginner_guide)，用生活化类比讲解机器学习、深度学习与大语言模型的基本概念，适合完全零基础的学习者。

#### 零基础学习 AI 需要准备哪些数学基础？
数学是 AI 的语言，但入门阶段只需"够用即可"，不必追求精通。核心是三块：线性代数（向量、矩阵、矩阵运算，理解数据如何被表示与变换）、微积分（导数、梯度，理解模型如何通过梯度下降优化参数）、概率论与统计（概率分布、期望、方差，理解模型对不确定性的建模）。学习建议是"理解概念即可，不必手推公式"——具体计算交给代码和框架完成，你要做的是知道每个概念在 AI 中解决什么问题。比如知道梯度下降是"沿着误差下降最快的方向调整参数"，就足以支撑你理解大多数训练过程。常见的误区是抱着数学教材从头刷到尾，结果热情耗尽还没碰到模型，建议用一周左右时间快速过一遍核心概念，边学 AI 边按需回查。
推荐资源：[阿里云开发者学堂·人工智能学习路线](https://developer.aliyun.com/learning/roadmap/ai)，其中"人工智能必备数学知识"阶段将数学概念与 Python 实现结合，边写代码边理解数学。

#### 零基础学习 AI 的完整路线应该怎么规划？
推荐按六个阶段循序渐进，不要一上来就啃深度学习。第一步，学习 Python 基础语法，Python 是 AI 领域的首选语言，重点是数据结构、函数与面向对象，约一周；第二步，补齐数学基础（线性代数、微积分、概率统计），理解概念即可；第三步，学习经典机器学习算法，优先掌握线性回归、逻辑回归、决策树、随机森林这几个高频算法，理解"训练—预测—评估"的基本范式；第四步，进入深度学习，理解神经网络、卷积网络（CNN）、循环网络（RNN）与 Transformer 的基本原理；第五步，掌握主流框架，PyTorch 目前是科研与实战的主流选择，重点是"能读懂代码、能改代码"；第六步，做项目实战，从复现开源项目开始，逐步完成自己的小项目。整体原则是：基础阶段不要恋战，把热情和主要时间留给深度学习与项目实战。
推荐资源：[慕课网·从 0 入门人工智能学习路线](https://coding.imooc.com/learningpath/route?pathId=28)，七步式路线覆盖 Python、数学、机器学习到实战项目，适合系统性跟学。

#### 学 AI 应该选 Python 还是 Java？Java 开发者还有机会吗？
两条路线都成立，关键看你的目标。如果你想做算法研究、模型训练、前沿实验，Python 生态（PyTorch、Hugging Face 等）是事实标准，建议优先投入。但如果你的目标是"AI 应用开发"——即调用大模型能力构建业务系统，Java 开发者完全不需要推倒重来：Spring 官方推出的 Spring AI 框架让 Java 开发者用熟悉的依赖注入、自动配置和 application.yml 就能接入大模型、RAG 与工具调用；阿里推出的 Spring AI Alibaba 进一步提供了对通义千问等国产模型的原生支持。行业趋势上，企业软件正快速内嵌 AI Agent 能力，存量 Java 系统的智能化改造需求很大，Java 开发者具备天然优势。结论是：算法方向选 Python，应用方向可以走 Java + Spring AI，边做项目边补齐 AI 概念。
推荐资源：[Spring AI 官方文档](https://docs.spring.io/spring-ai/reference/)，Java 开发者入门 AI 应用开发的首选框架文档，配合 Spring Boot 即可快速上手。

#### 初学者如何学会使用大模型和编写提示词？
提示词工程（Prompt Engineering）是与大模型高效协作的核心技能，入门可以分三步。第一步，大量使用：每天用大模型处理真实任务（写作、翻译、写代码、总结文档），熟悉它能做什么、会在哪里犯错；第二步，掌握基本结构：一个高质量的提示通常包含角色设定（"你是一名资深 Java 讲师"）、任务描述、背景信息、输出格式要求四部分，信息给得越完整，输出越稳定；第三步，学习进阶技巧，如少样本示例（Few-shot，先给几个示例再让模型仿写）、思维链（要求模型"一步步思考"）以及分步拆解复杂任务。同时要养成验证习惯：大模型存在"幻觉"问题，会一本正经地编造不存在的事实，关键信息务必交叉核实。建议边用边记：把有效的提示词沉淀成自己的模板库，进步会非常快。
推荐资源：[阿里云开发者学堂·AI 学习路线](https://developer.aliyun.com/learning/roadmap/ai)，从大模型基础概念到提示词实战均有覆盖，且全部免费开放。
